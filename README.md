# 🌍 Air Quality Analysis and Distribution – Power BI

## 📊 Project Overview

The **Air Quality Analysis and Distribution Dashboard** is an interactive **Power BI** project designed to analyze, visualize, and understand air quality and pollution patterns.

The dashboard provides insights into **Air Quality Index (AQI), pollutant levels, geographical distribution, and pollution trends** using interactive charts, KPIs, filters, and visualizations.

## 🎯 Objectives

* Analyze air quality levels across different locations.
* Identify areas with higher and lower pollution levels.
* Understand the distribution of AQI and major pollutants.
* Analyze pollution trends over time.
* Provide an interactive and easy-to-understand visualization of air quality data.
* Support data-driven understanding of environmental conditions.

## ▶️ How to View the Project

### Option 1 – Power BI Desktop

1. Download the `.pbix` file from this repository.
2. Install **Microsoft Power BI Desktop** if it is not already installed.
3. Open the `.pbix` file using Power BI Desktop.
4. Interact with the dashboard using the available filters, slicers, and visualizations.
